# Wanderly Version 3

A modern travel planning web app built with Python (Flask), HTML, CSS, and JavaScript.

## Run on your Mac

1. Open Terminal.
2. Go into the project folder:
   cd path/to/wanderly_v3
3. Install Flask:
   python3 -m pip install flask
4. Start the app:
   python3 app.py
5. Open the address shown in Terminal, usually:
   http://127.0.0.1:5000

## Features

- Modern responsive CSS interface
- Dashboard
- Multiple trips
- Trip budgets
- Itinerary activities
- Activity categories
- Automatic JSON data saving
- Delete trips and activities
- Works locally on your Mac
